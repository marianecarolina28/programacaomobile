Programação Mobile

Sobre

Este repositório foi criado para armazenar e organizar os trabalhos, atividades e projetos desenvolvidos na disciplina de Programação Mobile.

Objetivo

Reunir em um único lugar os conteúdos desenvolvidos durante as aulas, facilitando a organização dos projetos e o acompanhamento da aprendizagem na área de desenvolvimento mobile.

Conteúdo do Repositório

- Trabalhos acadêmicos
- Atividades práticas
- Projetos mobile
- Códigos-fonte
- Exercícios desenvolvidos em aula
- Outros materiais relacionados à disciplina

Tecnologias Utilizadas

- JavaScript
- React Native
- Expo
- Git
- GitHub

Organização

Os arquivos e projetos são organizados em pastas para facilitar a identificação, a manutenção e a consulta dos trabalhos realizados.

Finalidade

Este repositório tem finalidade acadêmica e será atualizado conforme novos trabalhos e atividades forem desenvolvidos durante a disciplina.
